#Portfolio

Full-stack portfolio starter with React + Vite frontend, Node.js + Express backend, and MySQL database.

## Requirements
- Node.js 18+
- MySQL 8+
- VS Code

## Run frontend
```bash
cd frontend
npm install
npm run dev
```

## Run backend
```bash
cd backend
npm install
npm run dev
```

Create `backend/.env` from `.env.example` and update the MySQL credentials.

## Database
Import `database/schema.sql` into MySQL.

## Admin
The admin dashboard is a starter interface. Authentication and database-backed editing routes are scaffolded for the next development phase.
